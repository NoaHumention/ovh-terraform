# Pipeline

Local Python pipeline that moves data through the data lake and into the
vector store, one stage per script:

```text
raw_data/ (local)
    |
    v  pipeline/ingestion/ingest.py
Bronze bucket (raw files)
    |
    v  pipeline/processing/process.py
Silver bucket (extracted, cleaned text)
    |
    v  pipeline/curation/curate.py
Gold bucket (chunked text)
    |
    v  pipeline/embedding/embed.py
vectordb (chunk text + embedding, in Postgres/pgvector)
```

Each stage script is standalone and can be run directly, e.g.:

```bash
python -m pipeline.ingestion.ingest
```

## Running the whole pipeline

```bash
python -m pipeline.run_pipeline
```

Runs all four stages in order and stops at the first failure.

## Embeddings

`pipeline/embedding/embed.py` embeds each chunk with a local, Dutch-tuned
sentence-transformers model:

```text
NetherlandsForensicInstitute/robbert-2022-dutch-sentence-transformers
```

It's a RobBERT (KU Leuven) model fine-tuned by the Netherlands Forensic
Institute for Dutch semantic similarity, producing 768-dimensional vectors.
Runs fully locally — no API key needed, but the first run downloads the
model (a few hundred MB) from Hugging Face and caches it.

Already-embedded chunks are skipped on re-runs (tracked by `chunk_id` in the
`chunks` table), so re-running the pipeline after new files arrive doesn't
re-embed everything from scratch.

## Automatic runs ("cron")

`pipeline/watch_and_run.py` is the scheduled entry point: it compares
`raw_data/` against a manifest of what it saw last time
(`pipeline/.state/raw_data_manifest.json`), and only runs the pipeline if
something is new or changed. It's meant to be triggered periodically by the
OS scheduler, not run as a long-lived loop.

See the main [README](../README.md) or ask for the Windows Task Scheduler
setup command to register it to run every 10 minutes.

## Setup

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

Requires a `.env` file at the project root (generated by `terraform apply`,
see `infra/locals.tf`) and a Terraform state with the `storage`, `IAM`, and
`vectordb` modules applied.
